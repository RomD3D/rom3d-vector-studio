Moteur de vectorisation

Rom3D Vector Studio utilise Potrace via le port WebAssembly potrace-wasm 1.0.4. Le traitement s’effectue localement dans le navigateur.

Potrace est un logiciel de Peter Selinger. Le port WebAssembly est fourni par Igute Chung sous GNU GPL version 2.

Les tracés sont des approximations de l’image source. Des petits détails peuvent nécessiter une retouche, particulièrement sur les images de faible résolution.
